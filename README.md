# Career Companion

build website with Step 1: Admin Adds Jobs

Our admin user will check government job advertisements from newspapers and official websites.
After collecting the job information, the admin will manually add:

Job title and department

Required education (Matric, FA, BA, etc.)

Age limit

Gender requirement

Domicile / province

Last date to apply

Total seats

The admin will also add all job-related costs, such as:

Bank challan fee

Post office fee

Photocopy charges

Expert service fee

The system will automatically calculate the total job cost.

Step 2: User Registration

Users will register on the website and enter:

Age or date of birth

Gender

Education level

Province and domicile

Uploading documents (CNIC, degrees, domicile, images) will be optional.

Step 3: AI Reads Documents (Optional)

If a user uploads documents, AI will read them and extract information like:

Education

Date of birth

Name

This data helps reduce mistakes and save time.

Step 4: Job Matching

The system will compare the user’s data with job requirements and show only those jobs for which the user is fully eligible.
Ineligible jobs will not be shown.

Step 5: User Selects Job

When a user selects a job, the website will show:

Job details

Eligibility summary

Complete fee breakdown

Total payable amount

Step 6: User Payment

The user pays the required amount using available payment methods.

Step 7: Expert Assignment

After payment:

A service expert is assigned

The expert contacts the user

Expert reviews documents and details

Step 8: Chat and Document Sharing

The user and expert can:

Chat on the website

Share documents

Share bank slips and forms

Step 9: Job Application

The expert applies for the job on behalf of the user by:

Filling forms

Submitting documents

Paying official fees

Step 10: Receipt Upload

After applying:

The expert uploads the application receipt

User can view it in their profile

Job status is marked as Applied

Step 11: Trust and Transparency

Users can:

Track application status

View payments and receipts

Chat history remains saved
